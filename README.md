# Social-Media-API
API соціальної мережі

Опис:
Вам потрібно створити RESTful API для платформи соціальної мережі. 
API повинен дозволяти користувачам 
створювати профілі, 
підписуватися на інших користувачів, 
створювати та отримувати пости, 
керувати вподобаннями та коментарями, 
а також виконувати базові дії, характерні для соціальних мереж.

Вимоги:

Реєстрація та автентифікація користувачів:

Користувачі повинні мати можливість зареєструватися за допомогою електронної пошти та пароля для створення облікового запису.
Користувачі повинні мати можливість увійти в систему за допомогою своїх облікових даних та отримати токен для автентифікації.
Користувачі повинні мати можливість вийти із системи та анулювати свій токен.

Профіль користувача:

Користувачі повинні мати можливість створювати та оновлювати свій профіль, включаючи фото профілю, біографію та інші дані.
Користувачі повинні мати можливість переглядати власний профіль та профілі інших користувачів.
Користувачі повинні мати можливість шукати інших користувачів за іменем користувача або іншими критеріями.

Підписка/Відписка:

Користувачі повинні мати можливість підписуватися та відписуватися від інших користувачів.
Користувачі повинні мати можливість переглядати список користувачів, на яких вони підписані, та список своїх підписників.

Створення та отримання постів:

Користувачі повинні мати можливість створювати нові пости з текстовим вмістом 
та необов'язковими медіавкладеннями (наприклад, зображеннями). (Додавання зображень є необов'язковим завданням)
Користувачі повинні мати можливість отримувати власні пости та пости користувачів, на яких вони підписані.
Користувачі повинні мати можливість отримувати пости за хештегами або іншими критеріями.

Вподобання та коментарі (необов'язково):
Користувачі повинні мати можливість ставити та знімати вподобання з постів. 
Користувачі повинні мати можливість переглядати список постів, які вони вподобали. 
Користувачі повинні мати можливість додавати коментарі до постів та переглядати коментарі до постів.

Планування створення постів за допомогою Celery (необов'язково):

Додати можливість планувати створення постів (можна обрати час створення посту перед його створенням).

Дозволи API:

Тільки автентифіковані користувачі повинні мати можливість виконувати такі дії, як створення постів, 
вподобання постів та підписка/відписка від користувачів.
Користувачі повинні мати можливість оновлювати та видаляти лише власні пости та коментарі.
Користувачі повинні мати можливість оновлювати та видаляти лише власний профіль.

Документація API:

API повинен бути добре задокументований з чіткими інструкціями щодо використання кожного ендпоінту.
Документація повинна містити зразки API-запитів та відповідей для різних ендпоінтів.

Технічні вимоги:

Використовувати Django та Django REST framework для побудови API.
Використовувати автентифікацію на основі токенів для автентифікації користувачів.
Використовувати відповідні серіалізатори для валідації та представлення даних.
Використовувати відповідні views та viewsets для обробки CRUD-операцій над моделями.
Використовувати відповідну маршрутизацію URL для різних ендпоінтів API.
Використовувати відповідні класи дозволів та автентифікації для реалізації дозволів API.
Дотримуватися найкращих практик проєктування та документування RESTful API.

Примітка: Вам не потрібно реалізовувати фронтенд-інтерфейс для цього завдання. 
Зосередьтеся на побудові добре структурованого та добре задокументованого RESTful API 
з використанням Django та Django REST framework. 
Це завдання перевірить навички junior DRF-розробника у побудові RESTful API, 
роботі з автентифікацією та дозволами, роботі з моделями, серіалізаторами, views та viewsets, 
а також дотриманні найкращих практик проєктування та документування API.
